# ft_push_swap

## Description

Sort a stack of integers in ascending order using only two stacks (`a` and `b`) and a limited set of operations (`sa`, `sb`, `ss`, `pa`, `pb`, `ra`, `rb`, `rr`, `rra`, `rrb`, `rrr`). The program outputs the list of operations that sorts stack `a`.

## Instructions

Compile:

```sh
make
```

Run (default strategy is `--adaptive`):

```sh
./push_swap 2 1 3 6 5 8
./push_swap --simple 5 4 3 2 1
./push_swap --medium 4 67 3 87 23
./push_swap --complex 4 67 3 87 23
./push_swap --bench 2 1 3 6 5 8
```

Clean:

```sh
make clean
make fclean
make re
```
